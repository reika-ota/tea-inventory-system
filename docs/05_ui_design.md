## 1. 共通デザイン

### 1.1 レイアウト
- スマートフォン縦画面を基準とし、コンテンツ幅は最大480pxで中央寄せする
- 上部にアプリバー（高さ56px）を固定表示する
- タブ画面（SC-02／SC-06／SC-07）のみ下部タブを表示する。それ以外の画面は下部タブを表示しない
- 入力フォーム画面（SC-04／SC-05）は、確定ボタンを画面下部に固定表示する
- タップ領域は最小44×44pxとする

### 1.2 配色（MUIテーマに設定する）

| 用途 | 色 |
|---|---|
| 背景 | `#eef1ec` |
| 面（カード・リスト） | `#ffffff` |
| 文字 | `#1d2621` |
| 補助文字 | `#5d6b62` |
| 区切り線 | `#d9dfd8` |
| プライマリ | `#3f6b3a`（淡色 `#e3ebdf`） |
| 期限切れ・削除 | `#b3261e`（淡色 `#f8e1de`） |
| 期限間近 | `#9a5f07`（淡色 `#f7ead2`） |
| 残りわずか | `#2f5b7a`（淡色 `#dfe9f1`） |

### 1.3 文字
- フォント：Zen Kaku Gothic New（Google Fonts）、代替として system-ui
- 数字は等幅数字（`font-variant-numeric: tabular-nums`）とし、残量や杯数の桁がそろうようにする
- 入力欄の文字サイズは16px以上とする（iOSで入力時に画面が拡大されるのを防ぐため）

### 1.4 アイコン
- Material Icons（@mui/icons-material）を原則とする。適切なものがない場合のみ独自に作成する

| 用途 | アイコン |
|---|---|
| 下部タブ：在庫／集計／設定 | EmojiFoodBeverage／BarChart／Settings |
| 戻る／閉じる／その他メニュー | ArrowBack／Close／MoreVert |
| 検索 | Search |
| 銘柄登録、杯数の増減、ジャンル追加 | Add／Remove |
| 購入・買い足し・再購入 | AddShoppingCart |
| 編集 | Edit |
| 削除 | Delete |
| 開閉 | ChevronRight／ExpandMore |
| このロットから飲む | LocalCafe |
| 残量を修正 | Tune |
| 賞味期限・購入日を修正 | Event |
| 使い切り | DoneAll |
| 復元／元に戻す | Restore／Undo |
| 並べ替え | ArrowUpward／ArrowDownward |
| アカウント／ログイン／ログアウト | AccountCircle／Login／Logout |
| 案内／エラー | Info／ErrorOutline |

### 1.5 お茶の色の丸（TeaCup、独自コンポーネント）
- 円の枠をジャンルの色、円の内側を下から塗りつぶす
- 塗りの高さ ＝ 有効ロットの残量合計 ÷ 有効ロットの購入量合計
- サイズ：一覧40px、詳細64px
- 装飾のため読み上げ対象外とする（aria-hidden）

### 1.7 強調バッジ

| 種別 | 表示 | 色 |
|---|---|---|
| 期限切れ | 期限切れ | 期限切れ色 |
| 期限間近（30日以内） | 期限間近 | 期限間近色 |
| 残りわずか（3杯以下） | 残りわずか | 残りわずか色 |
| 次に使うロット（SC-03） | 次に使う | プライマリ |

複数に該当する場合は、すべてのバッジを「期限切れ→期限間近→残りわずか」の順に並べる。

### 1.8 表示文言の統一

| 概念 | 画面上の表記 | 使わない表記 |
|---|---|---|
| 入庫 | 購入 | 入庫 |
| 消費 | 飲んだ | 消費 |
| 1回分 | 1杯 | 1回分 |
| 残量調整 | 残量を修正（操作）／残量修正（履歴） | 残量調整 |
| 使い切り | 使い切り | 削除 |
| 銘柄の論理削除 | 削除／復元 | － |
| 賞味期限なし | 期限未入力 | － |

履歴の区分表示：IN＝購入、CONSUME＝飲んだ（杯数指定時は「飲んだ（2杯）」）、ADJUST＝残量修正、DEPLETE＝使い切り、RESTORE＝使い切り取り消し

### 1.9 表示形式
- 数量：茶葉は `12g`／`12.5g`（小数がある場合のみ1桁）、ティーバッグは `8個`
- 日付：`2026/09/26`
- 期限：`期限 2026/10/25（あと28日）`、期限切れは `期限 2026/09/15（12日超過）`、なしは `期限未入力`

### 1.10 操作のフィードバック

| 部品 | 用途 | 仕様 |
|---|---|---|
| スナックバー | 操作の完了通知 | 3秒表示。「元に戻す」付きは6秒表示 |
| ダイアログ | 確認、数量・日付の入力 | キャンセルと確定の2ボタン。削除の確定ボタンは削除色 |
| ボトムシート | 操作メニュー（ロット・銘柄・ジャンル） | アイコン＋文言。実行できない項目は無効表示し、理由を併記する |
| 入力エラー | フォームの入力チェック | 項目の直下に表示し、確定時は最初のエラー位置までスクロールする |
| APIエラー | 通信・業務エラー | スナックバーで表示。競合（VERSION_CONFLICT）はダイアログで通知し、最新データを再取得する |

「元に戻す」付きのスナックバーは、使い切り（SC-03）と銘柄の削除（SC-03）の直後に表示する。

## 2. 画面別仕様

### 2.1 SC-01 ログイン
- 表示条件：自動ログインに失敗した場合、ログアウト後
- 表示項目：TeaCup（装飾）、アプリ名「Chaicoss」、説明文、Googleログインボタン（Google Identity Services の公式ボタン）、利用条件の案内
- 許可されていないアカウントの場合、ボタンの下にエラーを表示する：「このアカウントは利用できません。登録済みの家族のアカウントでログインしてください。」
- ログイン成功後は SC-02 を表示する

### 2.2 SC-02 在庫一覧
- アプリバー：タイトル「在庫」
- 注意の件数：期限切れ／期限間近／残りわずかの件数を3つ並べる。タップするとその条件で絞り込み、もう一度タップで解除する
- 検索欄：銘柄名とフレーバーの部分一致
- ジャンルチップ：「すべて」＋在庫のあるジャンル（色の点と件数付き）。横スクロール
- 形態の切り替え：すべて／茶葉／ティーバッグ
- 並び替え：注意が必要な順（初期値）／名前順／残りが少ない順／期限が近い順
- 銘柄の行：TeaCup、銘柄名（1行、はみ出しは省略記号）、ジャンル／フレーバー、強調バッジ、「あと○杯」（数字を大きく）、合計残量、最も近い期限。タップで SC-03
- 消費操作は置かない（誤操作防止）
- 絞り込み結果が0件の場合：「条件に合う銘柄はありません」と「絞り込みを解除」を表示する
- 在庫なし：有効ロットがない銘柄（削除済みを除く）を別枠で表示し、「再購入」ボタンで SC-05 へ
- 右下の追加ボタン（Add）で SC-04（新規）へ

### 2.3 SC-03 銘柄詳細
- アプリバー：戻る、銘柄名、その他メニュー（銘柄を編集／銘柄を削除）
  - 削除は有効ロットがある場合は無効とし、「在庫が残っているため削除できません」を併記する
  - 削除の確認後、SC-02 に戻り、「元に戻す」付きのスナックバーを表示する
- 概要：TeaCup、ジャンル／形態／1杯の量、フレーバー、合計残量とあと○杯、強調バッジ
- 消費パネル
  - 対象ロットの表示：「期限が近いロットから：残量／期限」。ロット指定中は「指定したロット」と「指定を解除」を表示する
  - 杯数ステッパー：初期値1、上限は対象ロットで飲める杯数。上限と下限では該当ボタンを無効にする。「最大○杯」を併記する
  - 主ボタン：「○杯飲んだ（○g）」
  - 補助ボタン：「量を指定して飲んだ」（数量入力ダイアログ）
  - 対象ロットの残量が1杯分未満の場合、主ボタンを「残り全部使った（○g）」に置き換え、「1杯分（○g）に足りません」を表示する
  - 有効ロットがない場合：「在庫がありません」と「再購入を登録」ボタン
  - 飲んだ結果、残量が0になった場合は使い切りの確認ダイアログを表示する（あとで／使い切りにする）
- ロット一覧：見出しに件数と「買い足し」ボタン。各ロットに残量／購入量、残量バー、「次に使う」と強調バッジ、期限、購入日、操作メニュー
  - 操作メニュー：このロットから飲む／残量を修正／賞味期限・購入日を修正／使い切りにする
- 使い切ったロット：折りたたみ表示（初期は閉じる）。各ロットに「元に戻す」
- 情報：ジャンル、フレーバー、形態、1杯の量、購入店、メモ。見出しに「編集」ボタン
- 履歴：新しい順に10件。区分（杯数）、日付、操作者、増減量、操作後の残量
  - 操作者はメールアドレスの@より前をそのまま表示する（例：`taro@example.com` → `taro`）

### 2.4 SC-04 銘柄登録・編集
- アプリバー：閉じる（Close）、タイトル「銘柄を登録」／「銘柄を編集」
- 入力項目

| 項目 | 必須 | 入力方法 | 補足 |
|---|---|---|---|
| 銘柄名 | ○ | テキスト（50文字） | 同じ名前の銘柄がある場合は注意を表示（登録は可）。削除済みと一致する場合は「設定から復元できます」と案内 |
| ジャンル | ○ | 色付きチップから1つ選択 | － |
| フレーバー | － | テキスト＋「追加」、またはEnter | 追加済みはチップで表示し、×で外す。既存銘柄のフレーバーを「候補」として表示し、タップで追加 |
| 形態 | ○ | 茶葉／ティーバッグ | 編集時、有効ロットがある場合は変更不可（理由を表示） |
| 1杯の量 | ○ | 茶葉：数値（g）、初期値3 | ティーバッグは入力欄を出さず「1個（ティーバッグは1杯＝1個）」と表示 |
| 購入店 | － | テキスト（50文字） | － |
| メモ | － | 複数行テキスト（200文字） | － |

- 確定ボタン：新規は「次へ：購入を登録」、編集は「保存」
- 新規登録は確定時点で銘柄を登録し、SC-05 へ進む（SC-05 で戻った場合、銘柄は在庫なしとして残る）
- 編集の保存後は SC-03 に戻る

### 2.5 SC-05 購入登録
- アプリバー：戻る、タイトル「購入を登録」
- 銘柄の概要：TeaCup、銘柄名、ジャンル／形態／1杯の量
- 有効ロットがある場合、「在庫が○ロットあります。今回の購入は別のロットとして登録します。」と案内する
- 入力項目

| 項目 | 必須 | 入力方法 | 補足 |
|---|---|---|---|
| 購入量 | ○ | 数値（g／個） | 前回の購入量を初期値とする（初回は空欄）。入力に合わせて「＝○杯分」を表示 |
| 賞味期限 | － | 日付 | 「わからない場合は空欄のまま登録できます」。入力後は「クリア」を表示 |
| 購入日 | ○ | 日付 | 初期値は当日。当日より後は不可 |

- 確定ボタン「購入を登録」。登録後は SC-03 を表示する

### 2.6 SC-06 ジャンル別集計
- アプリバー：タイトル「集計」
- 合計：在庫のある銘柄数、茶葉の合計（g）、ティーバッグの合計（個）
- ジャンル別：全ジャンルを表示順に表示する。色の点、ジャンル名、銘柄数、茶葉の合計（g）、ティーバッグの合計（個）。茶葉の合計は最大値を100%とするバーで比較する
- 在庫のないジャンルは薄く表示し、タップ不可とする
- ジャンルをタップすると、SC-02 をそのジャンルで絞り込んだ状態で表示する（他の絞り込みは解除）

### 2.7 SC-07 設定
- アプリバー：タイトル「設定」
- ジャンル：色の点、ジャンル名、銘柄数、操作メニュー（名前・色を変更／上へ移動／下へ移動／削除）
  - 削除は銘柄（削除済みを含む）から参照されている場合は無効とし、理由を併記する
  - 追加・変更はダイアログで行う：ジャンル名（20文字、重複不可）、色（色マスタの候補から選択。追加時は未使用の色を初期選択）
- 削除した銘柄：銘柄名、ジャンル、削除日、「復元」
- 使い切ったロット（最近10件）：銘柄名、購入量、使い切り日、「元に戻す」
- アカウント：ログイン中のメールアドレス、「ログアウト」（確認ダイアログあり）
- アプリのバージョン

## 3. 画面モックについて

画面モック（ui/wireframe.html）のうち、以下は表示確認用であり実装しない。

- 基準日を 2026/09/27 に固定している
- 賞味期限・購入量・購入日・履歴、「凍頂烏龍茶（サンプル）」はサンプル値
- SC-01 の「（モック）許可されていないアカウントの表示を確認」ボタン
- 操作者「あなた／家族」の表記（実装ではメールアドレスの@より前を表示する。2.3参照）
- データはページを再読み込みすると初期状態に戻る
- 画面遷移は画面内の状態で管理している（Claudeのプレビューの制約のため。実装では React Router の HashRouter を使う）
